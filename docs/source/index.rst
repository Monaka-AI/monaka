長単位・文節・係り受け解析器 Monaka
##############################

Monakaは長単位・文節境界解析、長単位語彙素（見出し語）解析、文節係り受け解析を実現する解析器です。
特徴としては、
   * 日本語を対象とした人文系研究での利活用を想定し、階層性を維持した解析結果の出力
   * 日本語に対して通時的に動作する解析器
となっていることです。
